# Conecta — prototipo Android

Base inicial con Expo Router + TypeScript.

## Instalar
```bash
npm install
```

## Ejecutar
```bash
npx expo start
```

Para Android:
```bash
npm run android
```

## Estructura
- `app/`: navegación y pantallas
- `src/theme/`: sistema visual
- `src/components/`: componentes reutilizables
- `src/data/`: datos mock del prototipo

El prototipo usa datos locales. Las APIs de Instagram, WhatsApp, TikTok y Facebook se incorporarán después mediante conectores separados.
