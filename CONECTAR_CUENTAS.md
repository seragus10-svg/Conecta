# Conectar cuentas

Ruta: `/(app)/profile/accounts`

Incluye Instagram, WhatsApp, TikTok y Facebook, con estado Conectada/No conectada, nombre de cuenta, Conectar y Desconectar.

La conexión actual es una simulación de interfaz y persiste localmente para probar el flujo. Los botones NO simulan una autenticación OAuth real: muestran claramente que falta conectar el flujo oficial de cada plataforma.
